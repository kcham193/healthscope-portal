How the sources fit together

  • Primary: Ministry of Health master facility registries — one per country, above.
  • Cross-reference: OpenStreetMap facility tags, used only to validate coordinates and flag likely coverage gaps. Never overrides the MoH record.
  • Not used: commercial listings, aggregators, or crowdsourced portals that don't disclose their upstream source.

All eight sources are refreshed on a rolling basis; see the About page for the ETL cadence.

Data Harmonization Methodology

All source datasets are harmonised to a common schema: unique facility ID, official name, administrative hierarchy (country / region / district), facility type (hospital / clinic / health centre), ownership (public / private / faith-based / NGO), GPS coordinates, operational status, last-verification date, and service availability indicators. Quality assessment includes duplicate detection, coordinate validation against the country bounding box, admin-hierarchy consistency checks, and temporal completeness.
